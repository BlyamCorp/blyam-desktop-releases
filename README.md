# Blyam Desktop

Этот репозиторий используется для распространения релизов приложения **Blyam Desktop**.

Здесь публикуются сборки приложения, доступные для скачивания и установки пользователями.

**Исходный код приложения хранится в отдельном приватном репозитории.**

Описания версий — в папке [`patch-notes`](patch-notes): приложение показывает их в «Настройки → Обновления» и в окне «Что нового» после обновления.
