## Исправления

- **Картинки в чатах.** Изображения больше не пропадают из-за истёкших ссылок, если приложение долго оставалось открытым. Ссылки для видимых картинок обновляются автоматически, в том числе при возвращении в чат.
- **Иконки серверов.** Исправлено появление стандартной иконки вместо загруженной после истечения ссылки на изображение.
- **Восстановление загрузки.** После временного сбоя сети приложение повторяет загрузку изображений — перезапускать его не нужно.
- **Просмотр изображений.** Обновление ссылок работает и в полноэкранном просмотрщике. При открытии вложения в браузере приложение запрашивает свежую ссылку.
