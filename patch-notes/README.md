# Патч-ноуты

Описания версий Blyam Desktop. Приложение загружает их отсюда: показывает в «Настройки → Обновления» и в окне «Что нового» после обновления.

## Файлы

- `index.json` — список версий, новые сверху:

  ```json
  {
    "versions": [
      { "version": "0.2.1", "date": "2026-10-28", "title": "Реакции на сообщения" }
    ]
  }
  ```

  `version` — как в теге без `v`, `date` — дата выхода (ГГГГ-ММ-ДД), `title` — короткий заголовок версии.

- `<версия>.md` — описание версии, например `0.2.1.md`. Поддерживается та же разметка, что в сообщениях: заголовки `##`, списки, **жирный**, *курсив*, `код`, ссылки.

## Как добавить версию

1. Создайте `<версия>.md`. Пишите для пользователей: что появилось и что стало лучше, без технических подробностей. Обычно хватает разделов «Новое», «Улучшения» и «Исправления».
2. Добавьте версию в начало `index.json`.
3. Отправьте изменения в `main` до или вместе с выходом релиза: приложение видит файлы сразу после публикации (GitHub может отдавать старую копию до 5 минут).
