## Улучшения

- **Обработка микрофона.** Более плавная автоматическая регулировка громкости и работа шумоподавления. Улучшена передача тихой речи и начала фраз, сокращено накопление задержки при нагрузке.
- **Качество трансляции.** Доступные профили учитывают разрешение выбранного окна или экрана, чтобы не увеличивать изображение без пользы для качества.
- **Сетевые уведомления.** Уточнены сообщения об ошибках связи. Звук потери соединения теперь совпадает с появлением предупреждения, а краткие перебои не вызывают лишних звуков. Для новых настроек звуки ошибок и потери/восстановления соединения выключены по умолчанию.

## Исправления

- **Стабильность трансляций.** Исправлены проблемы обработки кадров при просмотре и переключении трансляций, улучшена работа аппаратного кодирования.
- **Эмодзи серверов.** Исправлена загрузка изображений эмодзи после запуска приложения.
